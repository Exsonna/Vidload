## Key decisions

- **Generalized Referer (v0.4.14)** — learn the right `Referer` per registrable domain from `webRequest` `details.initiator` (the embed origin) instead of 3 hardcoded CDNs. Fixed downloads + metadata probe on Teachable/Hotmart and arbitrary CDN-gated sites. `all_frames:true` so player iframes are detected. **Also caught a latent bug: `build.mjs` hardcoded `all_frames:false` in dist — the published build never had the iframe fix.**
- **Real MP4, not .ts (v0.4.16)** — transmux MPEG-TS HLS → fragmented MP4 with vendored **mux.js** (~115 KB, no FFmpeg). See [[hls-download-approach]].
- **A/V muxing (v0.4.21)** — vendored **mp4box.js** (~147 KB, pure JS). DASH parser now extracts the best audio AdaptationSet + single-file `SegmentBase` reps (Reddit). Separate audio → download both → mux into one MP4 (codec config carried via the sample-entry `description` box, confirmed by reading mp4box's `addTrack` source). Fixes silent Reddit/Facebook/split-DASH. See [[dash-download-approach]].
- **YouTube without the cipher treadmill (v0.4.22, self-host only)** — instead of reverse-engineering YouTube's rotating `base.js` signature/n cipher, a MAIN-world hook captures the player's already-deciphered `googlevideo` URLs; the adapter cross-references them with player format metadata into a quality-selectable `mux` item. New full architectural note: [[youtube-capture-approach]].
- **`commit` vs `ship`** — committed verified work continuously (the user picked "commit first" before the muxer). Held the store upload + the monetization go-live behind explicit verification gates.
- **Monetization activation (v0.4.23–v0.4.25)** — trial timer rewritten around a bumpable `trialResetId` (re-grants everyone a fresh 7 days; set to `reliability-2026-06`). Live countdown header. Real ExtPay SDK swapped in for the stub + required `extensionpay.com` content script. Always-visible "Upgrade ✨" link. **Verified end-to-end with a Stripe test card → Pro unlock.** See [[monetization]].
- **No-YouTube-in-webstore discipline held** — the pre-flight `grep youtube dist/webstore/` caught my own slips (YouTube in shared-file comments) three times. Webstore build stays clean.
